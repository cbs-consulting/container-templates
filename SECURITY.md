# Security Policy

## Supported Versions

Only the latest published version of each Template receives security fixes.
Apply it again before you report a problem.

## Reporting a Vulnerability

Do not open a public issue for a security problem. Report it privately in one
of these ways:

- Through [GitHub private vulnerability reporting](https://github.com/cbs-consulting/container-templates/security/advisories/new).
- By email to [cp_opensource@cbs-consulting.de](mailto:cp_opensource@cbs-consulting.de),
  with [administrator@cbs-consulting.de](mailto:administrator@cbs-consulting.de)
  in copy.

Describe the problem, the affected Template and version, and the steps to
reproduce it. If you know of a fix or a workaround, add it as well.

We confirm that we received your report within five working days and keep you
informed while we work on a fix. Once the fix is released we publish a
security advisory and credit you, unless you would rather stay anonymous.

## Scope

This policy covers the Templates in this repository and the files they write
into a project. Problems in the base images, in the Dev Container Features the
Templates use, or in other third-party tools belong with those projects. For
the cbs Features, report them to
[container-features](https://github.com/cbs-consulting/container-features).
